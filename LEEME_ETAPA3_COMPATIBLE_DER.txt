PASOS (PowerShell en C:\Proyectos\sistema_denuncias_pirapo)
1. Confirmá que no haya cambios que te falte guardar en Git: git status
2. Copia de seguridad de los archivos visuales:
   New-Item -ItemType Directory -Force C:\Proyectos\respaldo_pirapo_etapa3 | Out-Null
   Copy-Item .\templates C:\Proyectos\respaldo_pirapo_etapa3\templates -Recurse -Force
   Copy-Item .\static C:\Proyectos\respaldo_pirapo_etapa3\static -Recurse -Force
3. Descomprimí el ZIP encima de la raíz del proyecto:
   Expand-Archive -Path "$env:USERPROFILE\Downloads\etapa3_ciudadano_compatible_der.zip" -DestinationPath "." -Force
4. Si el contenedor usa volúmenes de código (compose.yaml), reiniciá el servicio:
   docker compose restart web
   Si los cambios no se ven porque la imagen copia el código, ejecutá:
   docker compose up -d --build web
5. Verificá:
   docker compose exec web python manage.py check
   docker compose exec web python manage.py test
6. Abrí http://127.0.0.1:8000/ y actualizá con Ctrl+F5.
