Plataforma Web de Denuncias Ambientales - Pirapó

# Descripción

Proyecto orientado al desarrollo de una plataforma web para la gestión de
denuncias sobre problemáticas ambientales urbanas en el municipio de Pirapó.

El sistema permitirá a los ciudadanos registrar denuncias, adjuntar
evidencias fotográficas, indicar la ubicación del problema y consultar
posteriormente su estado.

Los funcionarios municipales podrán visualizar, organizar y gestionar
los reportes recibidos.

## Módulo desarrollado en esta etapa

Módulo de Registro de Denuncias Ambientales.

Permitirá:
- Registrar una denuncia.
- Seleccionar una categoría.
- Ingresar una descripción.
- Registrar el estado inicial.
- Adjuntar evidencia fotográfica.
- Registrar ubicación.

## Entorno de programación

- Lenguaje: Python
- Framework: Django
- Base de datos: PostgreSQL
- Frontend: HTML, Bootstrap y JavaScript
- Entorno: Docker
- IDE: Visual Studio Code
- Control de versiones: Git / GitHub

## Versiones

Python 3.14.7
Django 6.1.1

## Ejecución

El proyecto será ejecutado inicialmente en un entorno local mediante Docker.
